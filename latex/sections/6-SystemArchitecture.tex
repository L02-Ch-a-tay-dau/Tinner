\section{Sơ đồ kiến trúc hệ thống}

\subsection{Mô tả kiến trúc tổng quan}

Kiến trúc hiện tại gồm ba lớp chính và một tích hợp dữ liệu bên ngoài:

\begin{itemize}
  \item \textbf{Client layer}: mobile app Expo/React Native là kênh chính; web tham chiếu là thành phần phụ trợ.
  \item \textbf{API layer}: NestJS backend cung cấp REST API \texttt{/api/v1/*} với guard JWT toàn cục, validation và error handling thống nhất.
  \item \textbf{Data layer}: PostgreSQL (Aiven trên môi trường cloud, Postgres container ở local), truy cập qua Prisma.
  \item \textbf{External data}: SerpAPI (Google Maps engine) để lấy danh sách địa điểm ăn uống gần user theo toạ độ.
\end{itemize}

\subsection{Luồng xử lý \texttt{/suggestions}}

\begin{enumerate}
  \item Mobile gửi \texttt{lat}, \texttt{lng}, và có thể có \texttt{dishType}.
  \item Backend đọc bộ lọc user từ \texttt{user\_filters}.
  \item \texttt{SuggestionsService} thử gọi SerpAPI (nếu cấu hình API key) và đồng bộ dữ liệu mới vào DB.
  \item Service truy vấn DB theo dish/mixed mode, lọc theo rating, khoảng cách, cuisine, price.
  \item Kết quả được chuẩn hoá về payload restaurant và trả cho client để render thẻ swipe.
\end{enumerate}
